## 2026-09-06 - [Prevent Redundant Boxscore Network Fetches]
**Learning:** The application caches boxscore API responses globally using promises (`window.apiCache` and `window.liveApiCache`) during its 60-second polling cycle to deduplicate in-flight requests. Additionally, the main `/schedule` endpoint hydrates partial `linescore` data into global state (`currentGames` / `yesterdayGames`).
**Action:** When users interact with the UI (e.g., clicking to open a Box Score modal), always check these existing global variables and memory structures for pre-fetched promises or hydrated data *before* initiating new concurrent network fetch requests to prevent wasteful redundant API calls and UI lag.
